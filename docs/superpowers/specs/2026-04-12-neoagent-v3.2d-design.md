# neoagent v3.2d 设计规格：Session Recovery + Evaluation & Observability

日期: 2026-04-12
版本: v3.2d
前置: v3.2c（Channel/Interface）已合并 main，760 tests

## 目标

补齐 master spec 所定义的 11 个组件维度中最后两个缺口：

1. **session-recovery**：per-turn 自动存档、Resume 时合理性校验、存储清理，让 session 在崩溃/中断后可从最近快照恢复
2. **evaluation-observability**：UsageTracker（用量统计）、MetricsCollector（指标收集）、EvalRunner（批量评测），让 neoagent 支持生产级的可观测性与评测

## 范围

### 包含

**Session Recovery（3项）**
- `QueryLoop` per-turn auto-save：每轮工具调用结束后（及 end_turn 时）自动保存 session
- `NeoAgent.resume(validate=True)`：Resume 时校验 workspace 路径与上次活跃时间，校验失败通过 EventBus 发出警告而不阻断恢复
- `JsonFileStorage.cleanup(max_age_days, max_sessions)`：清理过期/超量 session 文件

**Evaluation & Observability（3项）**
- `UsageTracker`：订阅 `ProviderResponseEvent`，按模型统计 input/output token 用量
- `MetricsCollector`：聚合 per-turn 指标（token 数、延迟、工具调用次数），汇总为 `SessionMetrics`
- `EvalRunner`：批量执行 `EvalCase` 列表，收集每个 case 的独立指标，输出 `EvalReport`

### 不包含

- mid-tool checkpoint（turn 内崩溃丢当轮，接受此代价）
- 事件溯源（event sourcing）
- 快照加密 / PII 脱敏
- OpenTelemetry / Datadog 集成（EventBus 事件已足够，不引入外部可观测性框架）
- RL 训练管道
- 分布式追踪
- 多 Provider normalize_usage（SessionState 已有 total tokens 累计，足够）
- 外部 A/B 评测框架对接

## 设计决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| auto-save 粒度 | per-turn（每轮 tool_use 结束 + end_turn） | 崩溃最多丢一轮，成本可接受；mid-tool checkpoint 复杂度高收益低 |
| storage 引用传递方式 | Session 持有 `_storage` 引用（QueryLoop 调用 `session.save_if_storage()`） | 避免改变 QueryLoop 构造函数签名；Session 已是 QueryLoop 的主要参数，传递 storage 最自然 |
| run() auto-save | NeoAgent.run() 结束后 save（仅在 session 有 storage 时） | 与 chat() 行为对齐，之前 run() 缺失 auto-save 是 bug |
| resume 校验失败策略 | EventBus 警告事件（不抛异常，不阻断） | 恢复是最优先目标；用户通过订阅事件自决是否继续 |
| cleanup 返回值 | `list[str]`（被删除的 session_id） | 调用方可审计被清理的内容 |
| UsageTracker 未知模型 | 正常记录，model 字段存储原始字符串 | 用量统计不依赖 pricing，任何模型名都能记录 |
| MetricsCollector 延迟测量 | TurnStartEvent（新事件）记录开始时间，TurnCompleteEvent 记录结束 | 无 TurnStartEvent 时退化为 0（可接受；延迟是 nice-to-have） |
| EvalRunner 异常处理 | 捕获所有异常写入 EvalCaseResult.error，不中断批量 | batch eval 不能因单 case 崩溃中止 |
| eval 目录 | `neoagent/eval/` 独立包 | 与 core/tools/providers 平级；eval 关注点与运行时分离 |
| NeoAgent.enable_usage_tracking() 返回值 | 返回 `UsageTracker` 实例 | 便于调用方读取 `total_input_tokens` 等属性 |
| NeoAgent.enable_metrics() 返回值 | 返回 `MetricsCollector` 实例 | 与 enable_usage_tracking 风格一致 |

### 1.1 Session 新增字段与方法

**session.py 修改：**

```python
@dataclass
class Session:
    id: str
    messages: list[Message]
    state: SessionState
    created_at: datetime
    updated_at: datetime
    metadata: dict = field(default_factory=dict)  # 新增：workspace_path、last_active 等
    _storage: "SessionStorage | None" = field(default=None, repr=False)  # 新增：存档引用

    def save_if_storage(self) -> None:
        """如果绑定了 storage，执行 save；否则静默跳过。QueryLoop 调用此方法实现 per-turn auto-save。"""
        if self._storage is not None:
            self.save(self._storage)

    def bind_storage(self, storage: "SessionStorage") -> None:
        """绑定 storage，之后 save_if_storage() 生效。"""
        self._storage = storage
```

**序列化变更：**
- `_session_to_dict`：新增 `"metadata": session.metadata`
- `_session_from_dict`：新增 `metadata=data.get("metadata", {})`
- `_storage` 字段是运行时引用，**不序列化**

**JsonFileStorage.cleanup() 新增方法：**

```python
def cleanup(
    self,
    max_age_days: int = 30,
    max_sessions: int = 100,
) -> list[str]:
    """清理过期或超量的 session 文件。

    同时满足两个条件：
    1. 文件修改时间超过 max_age_days 天的文件被删除
    2. 剩余文件按修改时间排序，超出 max_sessions 数量的最旧文件被删除

    Returns:
        被清理的 session_id 列表（按删除顺序排列）
    """
    import time
    now = time.time()
    max_age_secs = max_age_days * 86400
    paths = sorted(self._base_dir.glob("*.json"), key=lambda p: p.stat().st_mtime)

    removed: list[str] = []

    # Pass 1: 删除超龄文件
    surviving = []
    for p in paths:
        if now - p.stat().st_mtime > max_age_secs:
            p.unlink(missing_ok=True)
            removed.append(p.stem)
        else:
            surviving.append(p)

    # Pass 2: 超量时删除最旧的
    if len(surviving) > max_sessions:
        to_remove = surviving[: len(surviving) - max_sessions]
        for p in to_remove:
            p.unlink(missing_ok=True)
            removed.append(p.stem)

    return removed
```

### 1.2 QueryLoop per-turn auto-save

`core/loop.py` 修改位置：两处 `turn.stop_reason` 确认后。

**工具调用轮（stop_reason="tool_use"）结束处：**

```python
# 追加 result_msg 到 msgs 之后（现有代码），添加：
turn = Turn(response=assistant_msg, tool_calls=tool_calls, tool_results=results, stop_reason="tool_use")
turns.append(turn)
self._bus.emit(TurnCompleteEvent(...))
if self._on_turn:
    self._on_turn(turn)
_session.save_if_storage()  # ← 新增：tool_use 轮 auto-save
```

**end_turn 轮结束处（return 之前）：**

```python
msgs.append(Message(role="assistant", content=response.content))
_session.save_if_storage()  # ← 新增：end_turn auto-save
return ConversationResult(turns=turns, reason="completed")
```

**实现说明：**
- `QueryLoop` 不需要修改构造函数：`_session` 已是 `run()` 内部变量，直接调用 `_session.save_if_storage()`
- `save_if_storage()` 是无副作用的空操作（`_storage is None` 时）—— 不影响现有无 storage 的调用路径
- max_tokens 提前返回路径（截断场景）也应 save，在相关 `return` 前加一行

### 1.3 NeoAgent.run() auto-save

`agent.py` 修改：`run()` 结束前添加 auto-save 逻辑（与 `chat()` 对齐）。

```python
async def run(
    self,
    messages: list[Message],
    session: Session | None = None,
    *,
    max_turns: int | None = None,
) -> ConversationResult:
    _temp = session is None
    if _temp:
        session = Session.create()
        session.messages = list(messages)
    elif session.messages:
        raise ValueError(...)
    else:
        session.messages = list(messages)

    # 绑定 storage，使 QueryLoop 内 save_if_storage() 生效
    if not _temp and self._storage is not None:
        session.bind_storage(self._storage)

    result = await self._loop.run(session=session, max_turns=max_turns)

    # run() 结束后 final save（QueryLoop 已做 per-turn save，此处做最终一次）
    if not _temp and self._storage is not None:
        session.save(self._storage)

    return result
```

**注意：`chat()` 同样需要在 loop.run 前 bind_storage，确保 per-turn auto-save 也在 chat 路径生效。**

### 1.4 NeoAgent.resume() 校验

`events.py` 新增事件：

```python
@dataclass(frozen=True)
class SessionResumeWarningEvent(Event):
    """Session resume 时校验失败发出的警告事件。不阻断恢复流程。"""
    session_id: str
    reason: str          # "workspace_missing" | "stale_session" | 用户自定义
    details: str         # 可读描述，如路径/时间差
```

`agent.py` 修改 `resume()` 方法：

```python
def resume(self, session_id: str, validate: bool = True) -> Session:
    """Load an existing session from storage.

    Args:
        session_id: 要恢复的 session ID。
        validate:   True 时执行合理性检验（默认开启）。
                    检验失败通过 EventBus 发出 SessionResumeWarningEvent，
                    但不阻断恢复——调用方通过订阅事件自决是否继续。

    Raises:
        RuntimeError: 未配置 SessionStorage。
        KeyError:     session_id 不存在。
    """
    if self._storage is None:
        raise RuntimeError("No SessionStorage configured. Pass storage= to NeoAgent.")
    session = Session.resume(session_id, self._storage)

    if validate:
        self._validate_resume(session)

    return session

def _validate_resume(self, session: Session) -> None:
    """执行 resume 合理性校验，失败发出 SessionResumeWarningEvent。"""
    from datetime import datetime, timezone, timedelta
    from neoagent.events import SessionResumeWarningEvent

    # 检验 1：workspace 路径是否存在
    workspace_path = session.metadata.get("workspace_path")
    if workspace_path is not None:
        from pathlib import Path
        if not Path(workspace_path).exists():
            self._event_bus.emit(SessionResumeWarningEvent(
                session_id=session.id,
                reason="workspace_missing",
                details=f"workspace_path={workspace_path!r} does not exist",
            ))

    # 检验 2：上次活跃时间是否过旧（超过 24 小时）
    _STALE_THRESHOLD = timedelta(hours=24)
    now = datetime.now(timezone.utc).replace(tzinfo=None)
    age = now - session.updated_at
    if age > _STALE_THRESHOLD:
        self._event_bus.emit(SessionResumeWarningEvent(
            session_id=session.id,
            reason="stale_session",
            details=f"last active {age.total_seconds() / 3600:.1f}h ago (threshold={_STALE_THRESHOLD})",
        ))
```

**用法示例：**

```python
warnings = []
agent.event_bus.subscribe(SessionResumeWarningEvent, warnings.append)

session = agent.resume("abc-123")  # 校验失败只发警告，不报错

if warnings:
    print(f"Resume 警告: {warnings[0].reason}")
    # 由调用方决定是否继续
```

```python
# neoagent/eval/usage.py
from __future__ import annotations

from dataclasses import dataclass, field
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from neoagent.events import EventBus, ProviderResponseEvent


@dataclass
class ModelUsage:
    """单个模型的 token 用量汇总。"""
    model: str
    input_tokens: int = 0
    output_tokens: int = 0
    request_count: int = 0


class UsageTracker:
    """追踪 agent 运行期间的 API 调用 token 用量（纯统计，不计算金额）。

    通过订阅 ProviderResponseEvent 自动收集数据。

    Usage::

        tracker = agent.enable_usage_tracking()
        await agent.chat("hello", session=session)
        print(f"Total input tokens: {tracker.total_input_tokens}")
        print(f"Total output tokens: {tracker.total_output_tokens}")
    """

    def __init__(self) -> None:
        self._per_model: dict[str, ModelUsage] = {}

    def _handle_response(self, event: "ProviderResponseEvent") -> None:
        """EventBus handler，由 enable_usage_tracking() 注册。

        注意：ProviderResponseEvent 不含 model 字段（Provider 在 create() 中已知 model）。
        UsageTracker 通过 provider.model 在 enable_usage_tracking() 绑定时获取模型名。
        若无法获取则记录为 "unknown"。
        """
        model = getattr(self, "_current_model", "unknown")
        if model not in self._per_model:
            self._per_model[model] = ModelUsage(model=model)
        usage = self._per_model[model]
        usage.input_tokens += event.input_tokens
        usage.output_tokens += event.output_tokens
        usage.request_count += 1

    @property
    def total_input_tokens(self) -> int:
        """所有模型的输入 token 总量。"""
        return sum(u.input_tokens for u in self._per_model.values())

    @property
    def total_output_tokens(self) -> int:
        """所有模型的输出 token 总量。"""
        return sum(u.output_tokens for u in self._per_model.values())

    @property
    def per_model_usage(self) -> dict[str, ModelUsage]:
        """按模型分组的用量统计。"""
        return dict(self._per_model)

    def reset(self) -> None:
        """清空所有已收集数据，可复用于新一次 eval case。"""
        self._per_model.clear()
```

**NeoAgent.enable_usage_tracking() 实现：**

```python
def enable_usage_tracking(self) -> "UsageTracker":
    """启用 token 用量统计。返回 UsageTracker 实例供读取结果。"""
    from neoagent.eval.usage import UsageTracker
    from neoagent.events import ProviderResponseEvent

    tracker = UsageTracker()
    # 将 provider.model 绑定到 tracker，使 handler 能获取模型名
    tracker._current_model = self._provider.model
    self._event_bus.subscribe(ProviderResponseEvent, tracker._handle_response)
    return tracker
```

```python
# neoagent/eval/metrics.py
from __future__ import annotations

import time
from dataclasses import dataclass, field
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from neoagent.events import EventBus


@dataclass
class TurnMetrics:
    """单轮次的指标快照。"""
    turn_index: int
    input_tokens: int
    output_tokens: int
    latency_ms: float        # 从 ProviderRequestEvent 到 ProviderResponseEvent 的耗时
    tool_call_count: int
    tool_names: list[str]    # 本轮调用的工具名列表（按调用顺序）


@dataclass
class SessionMetrics:
    """整个 session（或 eval case）的汇总指标。"""
    turns: list[TurnMetrics] = field(default_factory=list)

    @property
    def total_input_tokens(self) -> int:
        return sum(t.input_tokens for t in self.turns)

    @property
    def total_output_tokens(self) -> int:
        return sum(t.output_tokens for t in self.turns)

    @property
    def total_duration_ms(self) -> float:
        return sum(t.latency_ms for t in self.turns)

    @property
    def total_tool_calls(self) -> int:
        return sum(t.tool_call_count for t in self.turns)
```

**MetricsCollector 实现：**

```python
class MetricsCollector:
    """收集 agent 运行期间的 per-turn 和 session 级指标。

    订阅 EventBus 的以下事件：
    - ProviderRequestEvent：记录轮次开始时间
    - ProviderResponseEvent：记录 token 数，计算延迟
    - ToolCallEvent：累计工具调用次数和名称
    - TurnCompleteEvent：确认 turn_index 并封装 TurnMetrics

    Usage::

        collector = agent.enable_metrics()
        await agent.chat("hello", session=session)
        metrics = collector.get_session_metrics()
        print(f"Total turns: {len(metrics.turns)}")
    """

    def __init__(self) -> None:
        self._pending: dict[int, dict] = {}   # turn_index → 累计中间数据
        self._turns: list[TurnMetrics] = []

    def _on_provider_request(self, event) -> None:
        self._pending[event.turn] = {
            "start_ms": time.monotonic() * 1000,
            "input_tokens": 0,
            "output_tokens": 0,
            "tool_names": [],
        }

    def _on_provider_response(self, event) -> None:
        p = self._pending.setdefault(event.turn, {})
        p["input_tokens"] = event.input_tokens
        p["output_tokens"] = event.output_tokens
        start = p.get("start_ms")
        p["latency_ms"] = (time.monotonic() * 1000 - start) if start else 0.0

    def _on_tool_call(self, event) -> None:
        # ToolCallEvent 不含 turn_index；归入最新未完成轮
        if self._pending:
            latest_turn = max(self._pending.keys())
            self._pending[latest_turn].setdefault("tool_names", []).append(event.name)

    def _on_turn_complete(self, event) -> None:
        p = self._pending.pop(event.turn_index, {})
        tm = TurnMetrics(
            turn_index=event.turn_index,
            input_tokens=p.get("input_tokens", 0),
            output_tokens=p.get("output_tokens", 0),
            latency_ms=p.get("latency_ms", 0.0),
            tool_call_count=event.tool_call_count,
            tool_names=p.get("tool_names", []),
        )
        self._turns.append(tm)

    def get_session_metrics(self) -> SessionMetrics:
        """返回当前收集到的全量 session 指标。"""
        return SessionMetrics(turns=list(self._turns))

    def get_turn_metrics(self, turn_index: int) -> TurnMetrics | None:
        """返回指定 turn_index 的指标，不存在返回 None。"""
        for tm in self._turns:
            if tm.turn_index == turn_index:
                return tm
        return None

    def reset(self) -> None:
        """清空所有数据，用于 EvalRunner 的 per-case 复用。"""
        self._pending.clear()
        self._turns.clear()
```

**NeoAgent.enable_metrics() 实现：**

```python
def enable_metrics(self) -> "MetricsCollector":
    """启用指标收集。返回 MetricsCollector 实例。"""
    from neoagent.eval.metrics import MetricsCollector
    from neoagent.events import (
        ProviderRequestEvent, ProviderResponseEvent,
        ToolCallEvent, TurnCompleteEvent,
    )

    collector = MetricsCollector()
    self._event_bus.subscribe(ProviderRequestEvent, collector._on_provider_request)
    self._event_bus.subscribe(ProviderResponseEvent, collector._on_provider_response)
    self._event_bus.subscribe(ToolCallEvent, collector._on_tool_call)
    self._event_bus.subscribe(TurnCompleteEvent, collector._on_turn_complete)
    return collector
```

```python
# neoagent/eval/runner.py
from __future__ import annotations

from dataclasses import dataclass, field
from typing import Callable, TYPE_CHECKING

if TYPE_CHECKING:
    from neoagent.agent import NeoAgent
    from neoagent.core.types import ConversationResult, Message
    from neoagent.eval.metrics import SessionMetrics


@dataclass
class EvalCase:
    """单个评测用例。

    Attributes:
        name:      用例名称，唯一标识符（用于报告）。
        messages:  输入消息列表（将传入 agent.run()）。
        assertion: 断言函数，签名 (ConversationResult) -> bool。
                   True = pass，False = fail。
        max_turns: 覆盖默认的 max_turns（可选）。
        metadata:  用户自定义透传数据（标签、期望答案等）。
    """
    name: str
    messages: list["Message"]
    assertion: Callable[["ConversationResult"], bool]
    max_turns: int | None = None
    metadata: dict = field(default_factory=dict)


@dataclass
class EvalCaseResult:
    """单个 EvalCase 的执行结果。"""
    name: str
    passed: bool
    result: "ConversationResult | None"   # agent 成功执行时有值
    error: str | None                     # agent 抛异常时有值
    metrics: "SessionMetrics | None"      # 若启用了 MetricsCollector 则有值


@dataclass
class EvalReport:
    """批量评测报告。"""
    total: int
    passed: int
    failed: int
    cases: list[EvalCaseResult] = field(default_factory=list)

    @property
    def pass_rate(self) -> float:
        return self.passed / self.total if self.total > 0 else 0.0
```

**EvalRunner 实现：**

```python
class EvalRunner:
    """批量执行 EvalCase 列表，输出 EvalReport。

    每个 case 使用独立的 MetricsCollector 实例，互不干扰。
    agent 实例在 case 之间复用（共享工具注册、provider 配置）。

    Usage::

        runner = EvalRunner(agent)
        cases = [
            EvalCase(
                name="greeting",
                messages=[Message(role="user", content="Hello")],
                assertion=lambda r: "hello" in r.turns[-1].response.content.lower(),
            )
        ]
        report = await runner.run(cases)
        print(f"Pass rate: {report.pass_rate:.0%}")
    """

    def __init__(self, agent: "NeoAgent") -> None:
        self._agent = agent

    async def run(self, cases: list[EvalCase]) -> EvalReport:
        """顺序执行所有 case，收集结果，输出 EvalReport。

        异常不中断批量执行：任何 case 内的异常被捕获，
        记录到 EvalCaseResult.error，passed=False。
        """
        from neoagent.eval.metrics import MetricsCollector
        from neoagent.events import (
            ProviderRequestEvent, ProviderResponseEvent,
            ToolCallEvent, TurnCompleteEvent,
        )

        results: list[EvalCaseResult] = []

        for case in cases:
            # 为本 case 创建独立 MetricsCollector
            collector = MetricsCollector()
            self._agent.event_bus.subscribe(ProviderRequestEvent, collector._on_provider_request)
            self._agent.event_bus.subscribe(ProviderResponseEvent, collector._on_provider_response)
            self._agent.event_bus.subscribe(ToolCallEvent, collector._on_tool_call)
            self._agent.event_bus.subscribe(TurnCompleteEvent, collector._on_turn_complete)

            try:
                result = await self._agent.run(
                    messages=list(case.messages),
                    max_turns=case.max_turns,
                )
                try:
                    passed = bool(case.assertion(result))
                except Exception as assert_exc:
                    passed = False
                    result_for_report = result
                    error_msg = f"assertion raised: {assert_exc}"
                    results.append(EvalCaseResult(
                        name=case.name,
                        passed=False,
                        result=result_for_report,
                        error=error_msg,
                        metrics=collector.get_session_metrics(),
                    ))
                    continue

                results.append(EvalCaseResult(
                    name=case.name,
                    passed=passed,
                    result=result,
                    error=None,
                    metrics=collector.get_session_metrics(),
                ))

            except Exception as exc:
                results.append(EvalCaseResult(
                    name=case.name,
                    passed=False,
                    result=None,
                    error=str(exc),
                    metrics=collector.get_session_metrics(),
                ))
            finally:
                # 无论成功/失败，解除订阅避免下一 case 的数据污染
                self._agent.event_bus.unsubscribe(ProviderRequestEvent, collector._on_provider_request)
                self._agent.event_bus.unsubscribe(ProviderResponseEvent, collector._on_provider_response)
                self._agent.event_bus.unsubscribe(ToolCallEvent, collector._on_tool_call)
                self._agent.event_bus.unsubscribe(TurnCompleteEvent, collector._on_turn_complete)

        passed_count = sum(1 for r in results if r.passed)
        return EvalReport(
            total=len(results),
            passed=passed_count,
            failed=len(results) - passed_count,
            cases=results,
        )
```

## 八、不做的事（显式排除 YAGNI）

- **金额计算（pricing 变化频繁，由调用方自行处理）**：UsageTracker 只统计 token 用量；调用方拿到 per_model_usage 后可自行乘以当时的单价换算成美元
- **mid-tool checkpoint**：turn 内崩溃丢当轮，per-turn save 已是合理权衡
- **事件溯源**：EventBus 是 fire-and-forget，不需要回放机制
- **快照加密 / PII 脱敏**：session JSON 由调用方负责文件系统权限
- **OpenTelemetry 集成**：EventBus 已提供足够的可观测性接入点，不引入外部框架依赖
- **RL 训练管道**：EvalRunner 输出 ConversationResult，接入 RL 是调用方职责
- **分布式追踪**：neoagent 是本地框架，不需要 trace propagation
- **WebSocket 实时指标推送**：SSE 已在 v3.2c 覆盖
- **多 Provider normalize_usage**：SessionState.total_input/output_tokens 已做累计，足够
