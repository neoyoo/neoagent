# neoagent v3.2c 设计规格：Channel/Interface 抽象

日期: 2026-04-12
版本: v3.2c
前置: v3.2b（Multi-Agent）已合并 main，577 tests

## 目标

为 neoagent 添加 Channel/Interface 抽象层，让 NeoAgent 能通过不同传输协议对外暴露服务。v3.2c 交付：抽象基类 `Channel`（定义生命周期接口）+ 第一个生产可用实现 `FastAPIChannel`（HTTP 同步 + SSE 流式端点）。

## 范围

### 包含
- `Channel` ABC：`start() / stop() / serve_forever()` 三方法生命周期接口
- `FastAPIChannel`：基于 FastAPI + uvicorn 的 HTTP Channel
  - `GET  /v1/health`：存活探针
  - `POST /v1/run`：同步端点，返回完整 ConversationResult JSON
  - `POST /v1/run/stream`：SSE 流式端点，实时推送 agent 事件
- 无状态设计：每次 POST 创建新 session，不持久化跨请求状态
- asyncio.Queue 桥接：同步 EventBus handlers → 异步 SSE generator
- fastapi 作为可选依赖（`pip install neoagent[fastapi]`）
- httpx 加入 dev 依赖（用于测试 ASGI app）

### 不包含
- MQ Channel（Kafka/RabbitMQ 等，远期演进）
- WebSocket Channel（远期演进）
- 请求鉴权 / API Key（v3.3+ 考虑）
- 跨请求 session 持久化（无状态设计，不在本次范围）
- 对齐 Anthropic API 格式（自定义简单格式）
- gRPC Channel（远期演进）
- 并发请求限速（uvicorn 默认处理）

## 设计决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| Channel 生命周期 | `start() / stop() / serve_forever()` 三方法 | 与主流 server 框架（uvicorn、aio-pika）生命周期对齐；`serve_forever` 阻塞直到 `stop` 调用，适合进程主循环 |
| 第一个实现 | FastAPIChannel（HTTP） | FastAPI 生态成熟，Pydantic schemas 天然 + async；最常见的 agent 对外接口形态 |
| 无状态 | 每次 POST 创建新 session | 简化部署（无状态服务可水平扩展）；有状态会话由上层调用方管理 |
| SSE 流式 | Server-Sent Events（非 WebSocket） | 单向推送场景 SSE 足够；浏览器原生支持；不需要双向通信 |
| SSE 桥接 | asyncio.Queue 连接同步 EventBus 和异步 generator | EventBus.emit 是同步调用（在 agent 线程中），`queue.put_nowait` 线程安全；generator 侧 `await queue.get()` 自然等待 |
| API 格式 | 自定义简单格式，不对齐 Anthropic API | neoagent 是内部框架，对齐 Anthropic API 增加不必要复杂度；自定义格式更简洁 |
| fastapi 依赖 | Optional extra（`pip install neoagent[fastapi]`） | 不强迫不需要 HTTP 服务的用户安装 fastapi/uvicorn；延迟导入保证模块加载不报错 |
| app 属性 | `FastAPIChannel.app` property（懒构建） | 方便测试时直接用 httpx.ASGITransport，无需启动真实 uvicorn |
| SSE 开关 | `streaming: bool = True` 构造参数，`False` 时不注册 `/v1/run/stream` | 嵌入式/Worker 场景不需要 SSE，强制暴露反而增加攻击面；路由不注册比注册后返回 405 更干净 |
| MQ 兼容性 | Channel ABC 不假设传输类型，参数仅 `agent` | `start()`/`stop()` 无具体参数，MQ Channel 子类可在 `__init__` 接收 broker_url 等 |

## 一、Channel ABC

### 1.1 接口定义

```python
# neoagent/channels/base.py
from __future__ import annotations

from abc import ABC, abstractmethod
from typing import TYPE_CHECKING

if TYPE_CHECKING:
    from neoagent.agent import NeoAgent


class Channel(ABC):
    """Abstract base for neoagent communication channels.

    Subclasses implement a specific transport (HTTP, MQ, WebSocket, etc.)
    and wire it to a NeoAgent instance.

    Lifecycle::

        channel = MyChannel(agent, ...)
        await channel.start()          # bind port / connect broker
        await channel.serve_forever()  # block until stop() called
        await channel.stop()           # graceful shutdown
    """

    def __init__(self, agent: "NeoAgent") -> None:
        self._agent = agent

    @abstractmethod
    async def start(self) -> None:
        """Initialize the channel (bind port, connect to broker, etc.)."""

    @abstractmethod
    async def stop(self) -> None:
        """Gracefully shut down the channel."""

    @abstractmethod
    async def serve_forever(self) -> None:
        """Block until stop() is called."""
```

### 1.2 生命周期语义

| 方法 | 语义 | 幂等性 |
|------|------|--------|
| `start()` | 绑定端口 / 连接 broker，完成后 channel 处于 ready 状态 | 实现者自行保证 |
| `serve_forever()` | 进入事件循环，阻塞直到 `stop()` 被调用；内部可调用 `start()` 如未初始化 | 非幂等，调用一次 |
| `stop()` | 优雅关闭，等待 in-flight 请求完成后退出 | 建议幂等 |

### 1.3 未来 MQ Channel 兼容性示意

```python
class KafkaChannel(Channel):
    def __init__(self, agent, bootstrap_servers: str, topic: str):
        super().__init__(agent)
        self._bootstrap_servers = bootstrap_servers
        self._topic = topic

    async def start(self) -> None:
        self._consumer = AIOKafkaConsumer(self._topic, bootstrap_servers=self._bootstrap_servers)
        await self._consumer.start()

    async def stop(self) -> None:
        await self._consumer.stop()

    async def serve_forever(self) -> None:
        async for msg in self._consumer:
            await self._handle_message(msg)
```

ABC 的三个方法对 MQ 场景同样自然适配，无需修改接口。

## 二、FastAPIChannel

### 2.1 架构概述

```
HTTP Client
  │  POST /v1/run  (JSON)
  ▼
FastAPIChannel
  ├─ _build_app() → FastAPI ASGI app
  │   ├─ GET  /v1/health      → {"status": "ok"}
  │   ├─ POST /v1/run         → RunResponse (同步)
  │   └─ POST /v1/run/stream  → StreamingResponse (SSE)
  │
  ├─ /v1/run 处理流程：
  │   RunRequest → [Message] → NeoAgent.run() → ConversationResult → RunResponse
  │
  └─ /v1/run/stream 处理流程：
      RunRequest → [Message]
        → _sse_generator(messages, max_turns)
            → EventBus.subscribe(4 event types, sync_handlers)
            → asyncio.create_task(agent.run())
            → queue.get() loop → yield SSE lines
            → EventBus.unsubscribe (finally)
```

### 2.2 Pydantic 请求/响应 Schema

```python
class MessageIn(BaseModel):
    role: str
    content: str

class RunRequest(BaseModel):
    messages: list[MessageIn]
    max_turns: int | None = None

class RunResponse(BaseModel):
    turns: list[dict]   # [{stop_reason, text, tool_calls: [{name, id}]}]
    reason: str         # "completed" | "max_turns"

    @classmethod
    def from_result(cls, result: ConversationResult) -> "RunResponse":
        ...
```

### 2.3 SSE 事件格式

每条 SSE 消息格式：`data: <JSON>\n\n`

| 事件类型 | 触发时机 | JSON 字段 |
|----------|---------|-----------|
| `turn_complete` | 每轮结束 | `type, turn_index, stop_reason, tool_call_count` |
| `tool_call` | 工具被调用时 | `type, name, call_id, input` |
| `tool_result` | 工具返回时 | `type, name, call_id, is_error` |
| `response` | LLM 每次响应时 | `type, stop_reason, input_tokens, output_tokens, turn` |
| `done` | agent 正常完成 | `type, reason` |
| `error` | agent 抛异常 | `type, message` |

### 2.4 SSE 桥接原理

```
EventBus.emit(event)          ←── 同步调用（在 QueryLoop 协程中）
    │
    ▼
sync_handler(event):
    queue.put_nowait(event)   ←── 线程安全，asyncio.Queue
    │
    ▼
async _sse_generator():
    item = await queue.get()  ←── 等待事件
    yield f"data: {_event_to_sse_data(item)}\n\n"
```

关键细节：
- agent 完成时，`done_callback` 向 queue 放 `None`（sentinel）
- agent 抛异常时，`done_callback` 向 queue 放 `Exception` 实例
- `finally` 块保证无论正常/异常/客户端断开，handlers 都被 unsubscribe
- 客户端断开时 generator 被 GC，agent_task 被 cancel

### 2.5 完整实现

```python
# neoagent/channels/fastapi_channel.py
from __future__ import annotations

import asyncio
import json
import logging
from typing import TYPE_CHECKING, AsyncGenerator

from neoagent.channels.base import Channel
from neoagent.core.types import ConversationResult, Message, TextBlock
from neoagent.events import (
    Event,
    ProviderResponseEvent,
    ToolCallEvent,
    ToolResultEvent,
    TurnCompleteEvent,
)

if TYPE_CHECKING:
    from neoagent.agent import NeoAgent

logger = logging.getLogger(__name__)


def _get_fastapi():
    try:
        import fastapi
        return fastapi
    except ImportError:
        raise ImportError(
            "FastAPIChannel requires the 'fastapi' extra: "
            "pip install neoagent[fastapi]"
        )


def _get_uvicorn():
    try:
        import uvicorn
        return uvicorn
    except ImportError:
        raise ImportError(
            "FastAPIChannel requires the 'fastapi' extra: "
            "pip install neoagent[fastapi]"
        )


def _build_schemas():
    """Build Pydantic schemas using the already-imported fastapi pydantic."""
    from pydantic import BaseModel

    class MessageIn(BaseModel):
        role: str
        content: str

    class RunRequest(BaseModel):
        messages: list[MessageIn]
        max_turns: int | None = None

    class RunResponse(BaseModel):
        turns: list[dict]
        reason: str

        @classmethod
        def from_result(cls, result: ConversationResult) -> "RunResponse":
            turns = []
            for turn in result.turns:
                content = turn.response.content
                if isinstance(content, list):
                    text = "\n".join(b.text for b in content if isinstance(b, TextBlock))
                else:
                    text = content if isinstance(content, str) else ""
                turns.append({
                    "stop_reason": turn.stop_reason,
                    "text": text,
                    "tool_calls": [{"name": tc.name, "id": tc.id} for tc in turn.tool_calls],
                })
            return cls(turns=turns, reason=result.reason)

    return MessageIn, RunRequest, RunResponse


_STREAM_EVENT_TYPES = (
    ToolCallEvent,
    ToolResultEvent,
    TurnCompleteEvent,
    ProviderResponseEvent,
)


def _event_to_sse_data(event: Event) -> str:
    """Serialize *event* to a JSON string suitable for an SSE ``data:`` line."""
    if isinstance(event, TurnCompleteEvent):
        payload = {
            "type": "turn_complete",
            "turn_index": event.turn_index,
            "stop_reason": event.stop_reason,
            "tool_call_count": event.tool_call_count,
        }
    elif isinstance(event, ToolCallEvent):
        payload = {
            "type": "tool_call",
            "name": event.name,
            "call_id": event.call_id,
            "input": event.input_data,
        }
    elif isinstance(event, ToolResultEvent):
        payload = {
            "type": "tool_result",
            "name": event.name,
            "call_id": event.call_id,
            "is_error": event.is_error,
        }
    elif isinstance(event, ProviderResponseEvent):
        payload = {
            "type": "response",
            "stop_reason": event.stop_reason,
            "input_tokens": event.input_tokens,
            "output_tokens": event.output_tokens,
            "turn": event.turn,
        }
    else:
        payload = {"type": "event", "class": type(event).__name__}
    return json.dumps(payload)


class FastAPIChannel(Channel):
    """HTTP channel built on FastAPI + uvicorn.

    Exposes two endpoints:

    - ``POST /v1/run``         — synchronous, returns full ConversationResult JSON
    - ``POST /v1/run/stream``  — SSE stream of agent events
    - ``GET  /v1/health``      — liveness probe

    Each request creates a fresh, stateless session (no cross-request memory).

    Usage::

        agent = NeoAgent(config)
        channel = FastAPIChannel(agent, host="0.0.0.0", port=8000)
        await channel.serve_forever()
    """

    def __init__(
        self,
        agent: "NeoAgent",
        host: str = "0.0.0.0",
        port: int = 8000,
        streaming: bool = True,
    ) -> None:
        super().__init__(agent)
        self._host = host
        self._port = port
        self._streaming = streaming
        self._server: object | None = None
        self._app: object | None = None

    async def start(self) -> None:
        """Build the ASGI app and configure uvicorn (does not bind port yet)."""
        fastapi = _get_fastapi()
        uvicorn = _get_uvicorn()

        self._app = self._build_app(fastapi)
        config = uvicorn.Config(
            app=self._app,
            host=self._host,
            port=self._port,
            log_level="warning",
        )
        self._server = uvicorn.Server(config)

    async def stop(self) -> None:
        """Signal uvicorn to shut down."""
        if self._server is not None:
            self._server.should_exit = True

    async def serve_forever(self) -> None:
        """Start uvicorn and block until stop() is called.

        Calls start() automatically if it hasn't been called yet.
        """
        if self._server is None:
            await self.start()
        await self._server.serve()

    def _build_app(self, fastapi_module) -> object:
        FastAPI = fastapi_module.FastAPI
        StreamingResponse = fastapi_module.responses.StreamingResponse

        MessageIn, RunRequest, RunResponse = _build_schemas()

        app = FastAPI(title="neoagent", version="1.0")

        @app.get("/v1/health")
        async def health():
            return {"status": "ok"}

        @app.post("/v1/run", response_model=RunResponse)
        async def run(req: RunRequest):
            msgs = [Message(role=m.role, content=m.content) for m in req.messages]
            result = await self._agent.run(messages=msgs, max_turns=req.max_turns)
            return RunResponse.from_result(result)

        if self._streaming:
            @app.post("/v1/run/stream")
            async def run_stream(req: RunRequest):
                msgs = [Message(role=m.role, content=m.content) for m in req.messages]
                return StreamingResponse(
                    self._sse_generator(msgs, req.max_turns),
                    media_type="text/event-stream",
                    headers={"Cache-Control": "no-cache", "X-Accel-Buffering": "no"},
                )

        return app

    @property
    def app(self) -> object:
        """Return the ASGI app (build it if needed). Useful for testing."""
        if self._app is None:
            fastapi = _get_fastapi()
            self._app = self._build_app(fastapi)
        return self._app

    async def _sse_generator(
        self,
        messages: list[Message],
        max_turns: int | None,
    ) -> AsyncGenerator[str, None]:
        """Yield SSE-formatted strings for each agent event."""
        queue: asyncio.Queue[Event | BaseException | None] = asyncio.Queue()

        handlers: dict[type, object] = {}
        for event_type in _STREAM_EVENT_TYPES:
            def _make_handler(et=event_type):
                def _handler(ev: Event) -> None:
                    queue.put_nowait(ev)
                return _handler
            h = _make_handler()
            handlers[event_type] = h
            self._agent.event_bus.subscribe(event_type, h)

        async def _run() -> ConversationResult:
            return await self._agent.run(messages=messages, max_turns=max_turns)

        agent_task = asyncio.create_task(_run())

        def _on_done(fut: asyncio.Future) -> None:
            exc = fut.exception() if not fut.cancelled() else None
            queue.put_nowait(exc)

        agent_task.add_done_callback(_on_done)

        try:
            while True:
                item = await queue.get()
                if item is None:
                    result = agent_task.result()
                    yield f"data: {json.dumps({'type': 'done', 'reason': result.reason})}\n\n"
                    break
                elif isinstance(item, BaseException):
                    yield f"data: {json.dumps({'type': 'error', 'message': str(item)})}\n\n"
                    break
                else:
                    yield f"data: {_event_to_sse_data(item)}\n\n"
        finally:
            for event_type, handler in handlers.items():
                self._agent.event_bus.unsubscribe(event_type, handler)
            if not agent_task.done():
                agent_task.cancel()
                try:
                    await agent_task
                except (asyncio.CancelledError, Exception):
                    pass
```

## 七、远期演进

### 7.1 MQ Channel


Channel ABC 的三方法对 MQ 完全适用：`start` 连 broker，`serve_forever` 消费消息循环，`stop` 断开连接。

### 7.2 有状态 Session Channel

扩展 `FastAPIChannel` 或新增 `SessionChannel`，在 `/v1/sessions/{id}/run` 上持久化 session：

```
POST /v1/sessions          → 创建 session，返回 session_id
POST /v1/sessions/{id}/run → 追加消息并运行（复用已有 session）
DELETE /v1/sessions/{id}   → 销毁 session
```
