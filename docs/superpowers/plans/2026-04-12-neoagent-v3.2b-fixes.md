## Task 2: 显式 Session 传递 + 修复 work_summary（Critical）

**Files:**
- Modify: `neoagent/multi/task.py` (函数 `_run_worker`)
- Test: `tests/multi/test_task.py`

### 问题

`_run_worker()` 在 cancel/timeout 分支试图访问 `agent.session.messages`，但 `NeoAgent` 没有 `session` 属性。结果 exception 被吞掉，`work_summary` 降级为空（使用初始 messages 列表，不含真实执行历史）。

修复思路：在 `_run_worker()` 内显式创建 Session，传给 `agent.run()`。运行过程中 QueryLoop 会把消息追加到 session.messages，因此 cancel/timeout 时可以直接读取真实消息历史。

同时修复成功路径：成功时 `work_summary` 当前为 `None`，也用 `_extract_work_summary` 填充。

### 5a: Semaphore 等待阶段可取消

### 问题

当前：task 在 `tracker.track()` 后进入 `async with semaphore`，但 `set_asyncio_task()` 在拿到 semaphore 之后才调用。如果 semaphore 被占满，这段等待期内 `cancel_task()` 会返回 False（无 asyncio.Task 句柄）。

**修复思路**：把整个"等待 semaphore + 执行任务"包装成一个顶层 `asyncio.Task`，在 `tracker.track()` 之后立即注册，让 cancel 在等待阶段也生效。
